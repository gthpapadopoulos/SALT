# Third-party components

The frozen visual encoder is DINOv3, provided by Meta at
https://github.com/facebookresearch/dinov3. The release loads the official code
at commit `6876159a11b4df116f30f667f8c9888617df0751`. Its code and pretrained
weights remain subject to the upstream license and access terms. The backbone
weights and dataset images are not redistributed here.

The SALT release license has not been selected by the authors. This notice does
